小红书选品系统 v0.1.0（预发布）

## 包含
- 系统 1：用 USB 连接的安卓手机在小红书里按关键词、店铺、关键词→店铺采集商品，输出 CSV 和 Excel。
- 系统 2：每小时记录商品和店铺销量，计算增量，按规则推送提醒；本机网页界面（工作台、采集、商品、店铺、统计、日志、设置）。
- MCP 接入、可选访问令牌、面向非技术人员的图文教程（`docs/使用教程.pdf`）。

## 下载哪个
- Mac：`*-mac.zip`，解压后双击 `安装.command`，再双击 `启动.command`。
- Windows 10/11：`*-windows.zip`，解压后双击 `安装.bat`，再双击 `启动.bat`。
- 详细步骤见压缩包里的 `docs/使用教程.pdf`。需要已安装 Google Chrome。

## 已知限制（请先读）
- 手机采集只在 vivo V2547A、小红书 9.51.0 上验证过，App 改版后可能失效。
- Windows 版通过了 GitHub Windows 虚拟机的自动测试，但没有接真实手机采集过。
- push+、钉钉的真实发送，launchd 开机自启，每小时数千商品规模，连续采集几百个商品的稳定性，均未实测。
- 没有实时投屏（网页里只有手机截图预览）；系统 1 不采店铺粉丝数。
- 请控制使用频率并遵守平台规则，建议使用小号；采集内容仅供个人选品参考。
